# Lucid: notes for Claude

Unity 6 (6000.0.62f1) URP game jam project. Read `README.md` first for the layout, controls and current state.

- Game: Dream/Nightmare swap combat, 3D third-person, one level plus a boss. Deadline Sunday 15 Nov 2026 14:45.
- Most prefabs, materials and the level are generated by editor scripts in `Assets/Editor/`. Edit the builder, then run menu **Lucid > Build Props And Test Scene**. Do not hand-edit generated prefabs.
- `WorldState` (Dream/Nightmare) is the central switch. Use `WorldObject` to show something in one world only, and `WorldMaterialSwap` to change a material per world.
- Combat prefabs live in `Assets/Resources/Combat/` and are loaded by name through `CombatAssets.Get`.
- After editing C# or shaders, wait for Unity to finish compiling before running the builder, or it runs the old code.
- URP gotcha: `PI` is a macro in URP shader code, do not name a variable `PI`.
- Keep `CREDITS.md` up to date for every third-party asset.
- Do not commit the event deck PDF (Wi-Fi passwords). Ask before pushing large binaries outside Git LFS.
